# Verification Records

This directory contains reproducible evidence generated from the repository,
not marketing claims or hand-written test results.

- [`coverage/`](coverage/README.md): machine-readable and HTML coverage reports.
- [`test-results/`](test-results/README.md): JUnit test execution evidence.
- [`validation/`](validation/README.md): configuration and policy validation evidence.

Regenerate all evidence using the commands documented in each folder. Generated
timestamps describe the run, not the age or freshness of Fiverr market data.
